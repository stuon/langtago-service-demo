# Langtago Service Demo 🚀

> **Reference Microservice for EvidenceLog SOC 2 & ISO 27001 Automated Compliance Demonstrations.**

This service represents a production payment processing ingress microservice used to showcase how **EvidenceLog for Jira** captures cryptographic evidence across the SDLC:
- **Requirements Traceability (SOC 2 CC8.1)**
- **Git Code Linkage & Pull Requests (ISO 27001 A.8.32)**
- **Independent Peer Code Review & Segregation of Duties (SOC 2 CC6.8)**
- **Pre-Release QA Testing Confirmation (ISO 27001 A.8.29)**
- **Automated Security Scan Verification (SOC 2 CC7.1)**

---

## 🛠️ Tech Stack & Architecture
- **Runtime:** Node.js (v20+)
- **Security Protocols:** TLS 1.3 / Strict Transport Security (HSTS)
- **Compliance Integration:** EvidenceLog for Jira (Atlassian Forge)
